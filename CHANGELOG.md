## [0.1.0] - 2026-08-14

### Added

- Initial release of `cake-instruckt` as an independent open-source project inspired by [instruckt](https://github.com/joshcirre/instruckt).
- Visual feedback and screenshot tooling for AI coding agents.
- Framework adapters for Livewire, Vue, Svelte, React, and Blade.
- Vite integration with a built-in development API server.
- Customizable toolbar items and buttons.
